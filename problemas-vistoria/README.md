# Problemas da vistoria — Apto 202

Página criada para organizar os defeitos identificados na entrada do apartamento 202 do Condomínio Arlindo Cunha e facilitar o envio das evidências à imobiliária.

## Estrutura
- `index.html`: página pública com a lista dos problemas e links para os vídeos.
- `email.txt`: modelo de e-mail para comunicação formal à imobiliária.
- `videos/`: pasta esperada para os arquivos de vídeo.
